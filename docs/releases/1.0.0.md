# xsoc 1.0.0

正式资产见 [xsoc v1.0.0](https://github.com/isarmg/xsoc/releases/tag/v1.0.0)。构建、运行与安装验收证据以该标签指向的精确源码和对应官方工作流为准。

## 变更

- 精确消费官方 xcsc 1.0.0；只保留 --config / --format 当前参数。
- probe / doctor 的 NDJSON 输出为单行；区分已输出的不健康诊断与未输出的实际失败，取消不再冒充已完成。
- 交互授权码使用公共隐藏输入；同步软件版本与安装器元数据。
- Windows 安装器使用维护程序的独立副本，避免把 Cargo 的构建硬链接作为发行清单输入。

公共客户端源固定为 `6fca4299f5c34a79db1c7bd4e889b418d2a58e2d`。软件补丁号独立于业务协议、持久状态与 FFI ABI。

业务协议源码固定为 `xsos@0cc4430da371deff3aa5a45a2397f6c42e457eea`；对应协议包与业务格式为 `1.0.0` / `v1`。公共发行工具固定为 `3441aa1e36861ae961371be3e0ce4636d649c6c1`。

## 验证与交付

各平台的编译、原生运行和安装生命周期由相应平台工作流验证。正式包的外部 SHA256 与包内完整清单绑定全部交付文件、运行依赖及原始许可证；公开版本的验证结果以对应 v1.0.0 Release 和最终源码工作流记录为准。
