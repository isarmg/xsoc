# xsoc 1.0.1

- 为磁盘速率建立采样基线，避免初始累计值被误报为当前速率。
- 合并 GPU 身份信息，修正可选 GPU 采集特性下的编译问题。
- 报告 OTLP 部分成功结果，让未完全接收的遥测上报可见。
- 在客户端命令间一致应用显式选择的配置，正常关闭时取消客户端拥有的 SMART 采集任务。
- 公共客户端支撑升级至 `xcsc 1.0.1`，固定 revision `d3e9b8db84e4ead70ec0bf8a596dbad697f7db24`；业务协议继续使用 `xsos-protocol 1.0.0`。
- 完善 Linux、Windows 和 macOS 的安装、维护与集成说明。

## 安装包

Windows x64 MSI、Linux x86_64 DEB/RPM、macOS arm64 未签名 PKG，以及 manifest 和 SHA-256 校验和。软件、WiX 产品版本和 Linux 包生命周期版本统一为 `1.0.1`；报告 schema 1、配置和持久状态格式 `1.0.0` 保持兼容。

安装、配置与更新步骤见[平台部署指南](../platform-setup.md)。
