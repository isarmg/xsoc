# xsoc 1.0.4

## 本次变更

- 常驻 `run` 的每份报告都声明配置采样周期。短启动预热或长时间暂停不再使服务端按错误周期估算主机在线状态，避免十秒采样的主机恢复上报后再次断线，却仍被按一小时周期判断为在线。
- 网络和磁盘速率继续按真实采样时间计算，累计值、采集时间和报告 ID 不变；断线补传保持原报告字节，不重写已有队列。
- `probe`、`once`、`doctor --delivery` 和移动宿主的间隔行为保持原样。服务端按样本聚合指标，修复不改变统计权重。
- 软件版本、Windows MSI 默认版本和 Linux 包生命周期版本更新为 1.0.4；当前安装示例同步该版本。

## 兼容性

继续固定 `xcsc 1.0.3`（`5641a33e991209eecdbbc91cffaa3be545875757`）与 `xsos-protocol 1.0.0`（`3b5c437a80424c717a20ffbad07c3e8d01cd83ae`）。报告 schema 1、配对协议 1、配置和持久状态格式 `1.0.0` 均未改变，不要求更新服务端。

## 验证边界

本地使用合成报告和临时 sysfs 夹具验证计数、速率、暂停恢复与队列编码，独立复核覆盖实际服务端状态函数和在线统计 SQL。本地没有采集真实主机、执行完整 Rust 测试或构建原生安装包。完整 Linux、Windows、macOS 构建及安装生命周期验证以最终提交的 CI 为准；本页为发布准备，不表示正式资产已发布。
